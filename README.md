# 📚 Library Management System

A web-based application for book management and smart data extraction using web scraping techniques.

## 🎯 Features

- **CRUD Operations** - Add, update, delete, and view books
- **Smart Search** - Search by title, author, or ISBN
- **Web Scraping** - Auto-fetch book summaries using JSoup
- **Responsive UI** - Modern React frontend
- **Database** - MySQL backend with JDBC

## 🛠️ Tech Stack

| Layer | Technologies |
|-------|--------------|
| Frontend | React, CSS3, Axios |
| Backend | Java, JDBC, JSoup, Gson |
| Database | MySQL |
| Build | Maven |

## 🚀 Quick Start

### Prerequisites
- Java JDK 11+
- MySQL Server
- Node.js & npm
- Maven

### Installation

**1. Clone & Setup Database**
```bash
git clone https://github.com/yourusername/library-management-system.git
cd library-management-system
mysql -u root -p -e "CREATE DATABASE library_db;"
```
